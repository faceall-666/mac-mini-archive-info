Mac-mini-Archive

Privacy Policy

Effective and last updated: 15 October 2026

Purpose and operator

Mac-mini-Archive is operated by the repository owner for personal, local archiving. This public website contains information only. It does not receive archive files, passwords, OAuth authorization codes, access tokens, or refresh tokens.

Data the integration accesses

The locally operated integration processes files selected by the owner, including their contents and relevant metadata such as names, sizes, timestamps, file identifiers, and checksums. It may read Drive storage usage. Google OAuth provides the access and refresh tokens needed for the authorized operations.

The requested Google permission is https://www.googleapis.com/auth/drive.file. It permits access to files created by or specifically authorized to this integration, not unrestricted access to the entire Drive account. This integration does not request Gmail, Google Photos, contacts, or calendar access.

How data is used

Data is used only to carry out owner-authorized archive operations: copying selected files to Google Drive, listing relevant archive metadata, checking storage capacity, downloading files, and verifying restoration. Local tools and authorized assistants may perform these operations under the owner's instructions.

The operator does not sell Google user data or use it for advertising, profiling, or training generalized artificial-intelligence or machine-learning models. Google user data is not published in this information repository. Any access by a separately authorized tool remains subject to the owner's instructions and that tool's applicable data practices.

Storage and security

Archive files are stored in the owner's Google Drive. Local configuration and OAuth credentials are stored outside project repositories, with owner-only operating-system permissions. Setup uses a private configuration directory and restricts credential files to the operating-system owner. These permissions are not encryption and do not isolate programs running as that same user.

Local receipts may record file paths, identifiers, sizes, and hashes to support restoration. Such receipts and credentials are not part of this public website. Network operations use the providers' HTTPS services. No system can guarantee uninterrupted authorization, immutable archives, or recovery from every loss.

Retention, deletion, and revocation

Files remain in Google Drive until the owner removes them, subject to Google's retention and trash policies. Local copies and receipts remain until separately removed by the owner or an authorized maintenance process. Upload does not automatically remove a local source.

The owner can revoke this integration through Google Account third-party connections. Revoking access does not itself delete archive files. To delete archives, the owner must remove the relevant files from Drive separately. Local credentials can also be removed through a separately authorized local maintenance action.

This website and third-party providers

This static website has no application backend, forms, analytics scripts, advertising, or tracking cookies added by the operator. GitHub Pages may process visitor information, including IP addresses, for hosting and security. Google processes information needed to provide Drive and authentication. Their own policies apply to their services: GitHub Privacy Statement and Google Privacy Policy.

Google API Limited Use

Mac-mini-Archive's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Contact and changes

For questions about this personal integration, contact the repository owner through their public GitHub profile. Updates to these practices will be reflected on this page with a revised date.
