Personal archive integration

Mac-mini-Archive

Mac-mini-Archive is a personal integration for its owner's Mac mini. It uses the locally installed rclone command-line tool to copy selected archive files to the owner's Google Drive and retrieve them when needed.

This is an information website, not a storage or sign-in portal. It has no upload form, Google authorization flow, application server, or public registration.

What the integration does

  • Allows the owner and authorized local tools to upload selected files into a dedicated archive area.
  • Reads relevant file metadata and available storage capacity.
  • Downloads archive files and compares cryptographic hashes to check restoration.
  • Keeps local deletion separate from upload. A completed upload does not automatically delete its source.

Google Drive access

The integration requests the limited drive.file permission. It can manage files created by or specifically authorized to this integration, rather than requesting access to every file in the account. Google sign-in and consent occur on Google's own pages during local setup, not on this website.

It is intended for personal use, not as a public service. Authorization can be revoked, and its continued validity is subject to Google's policies. It is not a promise of immutable storage or guaranteed recovery.
